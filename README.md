This is file setup for Web-AI workshop conducted by Dr. Suhailan Safei.

It will set opencode to use CodeIgniter 4 as the main framework and running automatically using XAMPP localt environment. 

It will also automatically "allow changes" without the need to ask permission,  and run "/compact" command to avoid opencode restriction if the usage is above 50%.

Copy "opencode.json" file and ".opencode" folder into your opencode main project folder.
